# Agent Guidance

## Project

Progene is an experimental project for exploring co-evolution between agents and their harness. Keep changes focused on that purpose and avoid introducing unrelated application scaffolding.

## Working in This Repository

1. Read `README.md` for the current project scope.
2. Check `.agents/skills/` for a skill that matches the task and follow it before making changes.
3. Preserve the existing structure and naming conventions of any skill you edit.
4. Keep instructions concise, actionable, and organized around observable completion criteria.
5. Update directly related documentation when behavior, workflow, or project scope changes.

## Agent-Facing Documentation

When creating or editing skills, `AGENTS.md`, or other instructions consumed by agents, follow `.agents/skills/writing-for-agents/SKILL.md`. For skill packaging, invocation, frontmatter, or routing changes, also read `.agents/skills/writing-for-agents/SKILL-MECHANICS.md`.

Prefer pointers to task-specific reference material over copying it into always-loaded instructions. Keep each rule in one authoritative location.

## Validation

Use the smallest available check that covers the change. For documentation-only changes, review links, paths, structure, and wording for accuracy and consistency.
